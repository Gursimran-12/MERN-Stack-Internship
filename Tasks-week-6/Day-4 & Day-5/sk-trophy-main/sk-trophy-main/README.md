SK Trophy 🏆

A modern, responsive React web application built using **Vite + React** and deployed on **Vercel**.

This project showcases clean UI design, structured component architecture, and production-ready deployment practices.

---

- JavaScript (ES6+)
- CSS

## 🛠️ Installation & Setup

Clone the repository:

bash
git clone https://github.com/inderpaltaur/sk-trophy.git
cd sk-trophy

Install dependencies:

npm install

Run development server:

npm run dev

Build for production:

npm run build

Preview production build:

npm run preview


Deployment

This project is deployed using Vercel.

To deploy:

Connect GitHub repository to Vercel

Set framework preset to Vite

Build command: npm run build

Output directory: dist
